Beyond “Write Me SQL”: An Evidence-Driven AI Workflow for Data Warehousing

Real development lessons. Clear agent responsibilities. Safer context sharing. Tests with an honest boundary.

By Derin Ege Evren·AI & Machine Learning Engineer·About 17 min read

A sixteen-page field guide for data practitioners moving from isolated prompts to a repeatable way of working with AI. Its starting point is that a successful run is not the same as a verified result. From there it builds a workflow around three questions: what must be true (context), who owns the change (responsibility) and what did we actually prove (evidence), with a real development case, a security section on sharing structure rather than sensitive data, and a starter workflow for a junior data engineer.

Companion piece to GPT-6 Astra vs Claude Fable 5: Beyond the Benchmark. Examples are anonymized.
